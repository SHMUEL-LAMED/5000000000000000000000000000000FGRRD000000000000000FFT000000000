הדפדפן הפרטי שלי

זהו דף הכניסה לפרויקט. הדפדפן עצמו פועל ב־Cloudflare ומוגן באמצעות Cloudflare Access.

פתח את הדפדפן

אם נטפרי מציגה הודעת חסימה, כתובת השירות עדיין לא זמינה ברשת שלך. דף GitHub זה אינו מפעיל את הדפדפן לבדו.

הגרסה הנוכחית מציגה צילום מסך וטקסט מדף ציבורי. אין עדיין שליטה בעכבר או הקלדה בתוך האתר.
